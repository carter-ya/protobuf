# Codec baseline: 2026-10-31

Measured on Apple M5 Max, macOS-27.0.1-arm64-arm-64bit, go version go1.27.0 darwin/arm64 and libprotoc 36.2, with one benchmark CPU, three samples and 100 ms per sample. The current measured source is `1379b67a5ed7769cfa90367a270048216eef2cc3`; the checkout was clean. Original v1.3.2 is `b03c65ea87cdc3521ede29f62fe3ce239267c1bc` and the pre-Version13 extension reference is `9cba925c0b5bf1a8ed530583d0af6c1afa1af019`.

All 35 profile/backend combinations completed: 160 operation rows and 480 samples. The two payload sizes are 64 and 4096 bytes, with eight map entries and fixed scalar/message fields. Counts refer to payload bytes; the CSV records actual wire lengths. See [environment](baseline/2026-10-31/environment.json), [CSV medians](baseline/2026-10-31/results.csv), [JSON medians](baseline/2026-10-31/results.json) and [raw samples](baseline/2026-10-31/raw).

## Revision comparisons

Ratios are current median ns/op divided by reference median ns/op. Greater than 1 means more time. These are short local microbenchmarks, not confidence intervals or release thresholds. Compare the same backend within a family.

Fast proto2 encode/decode medians stay close to the original in this fixture. Reflection proto2 decoding is about 1.7–1.8× slower, with 57 allocations versus 41 for the original. The additional 16 allocations coincide with the eight map entries, but this is an observation rather than a confirmed allocation-site diagnosis. Profile and reduce that overhead before setting a release performance budget. No regression is hidden by a speed gate.

Extension decoding now validates registered native message payloads eagerly instead of deferring their errors until a read. The measured roughly twofold decode cost is visible in the table; decode+read provides a closer comparison for callers that consume extensions. This report does not attribute every timing change to validation alone.

## Reproduction and scope

Check out the measured source revision above and run the [documented command](README.md) with the recorded toolchain on otherwise idle hardware. Harness/template SHA-256 values and the exact snapshot revisions are in the environment file. Only temporary snapshot `go.mod` developer dependencies are removed; production source is unchanged.

The common fixture has no oneof because the unmodified original gogotypes comparison generator panics when it encounters ordinary fields alongside a oneof. Functional matrices cover oneofs separately. This run does not measure custom/cast/standard representations, JSON/text, concurrency, pathological inputs or every message shape. CI only checks fixture execution and output inventory at one iteration; it makes no speed claim.
