# Legacy compatibility checks

`compat/legacy` is an independent consumer module. Its generated files are
frozen output of gogo/protobuf v1.3.2 (b03c65e), generated with protoc 36.2.
Do not regenerate these fixtures while updating the generator or runtime.

Run `sh compat/check.sh` with protoc 3.21.8 or 36.2 on PATH. It checks two independent
paths: frozen generated code against the candidate runtime, and unchanged
schemas regenerated by the candidate generator. The root suite also covers
proto2 defaults, extensions, custom types, WKT and the existing plugin matrix.

The version helper accepts both historical three-component versions and modern
two-component versions. CI checks both compiler families.

The v1.3.2 golden generator tests require protoc-min-version and protoc-gen-gogo
on PATH; the script builds them before running the suite. The consumer uses
replace to keep original imports and avoid linking two runtime identities.
Historical integration tests run in a disposable GOPATH-shaped copy because
some resolve proto imports through relative paths. No source tests are skipped.
The historical `testdata/multi` goldens are ignored by the original repository.
`compat/golden/multi` freezes them using the original v1.3.2 generator; the
script copies those references into the disposable suite before testing.

Generated snapshots compare Go syntax and decompressed descriptor bytes. This
ignores only comments, formatting and gzip representation, which vary between
Go toolchains. Field tags, declarations, function bodies and descriptor data
must match; frozen consumer files are still compiled without modification.
